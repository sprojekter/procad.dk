# 1. Inspirationsanalyse og mønstre

Analysen bygger på gennemgang af danske konkurrenter (daugaards-cad.dk, roennowdesignogit.dk, cadtegn.dk, mps-tegnestue.dk, mhkonstruktion.dk) og internationale referencer for UX (cadcam.org, cadmore.com). Der er ikke kopieret tekst eller design.

## Konklusion

Det danske marked er præget af forældede, tekstbaserede sider uden cases og uden fil-upload. De internationale sider er bedre til struktur og CTA'er, men konkurrerer på pris og mangler det lokale. **ProCAD skiller sig ud på design, dokumentation (før/efter) og lav friktion (upload først).**

| Typisk hos konkurrenter | Det gør ProCAD i stedet |
|---|---|
| Lange tekstvægge | Korte afsnit, tydelig hierarki, lister og tegningsark-rammer |
| Ingen cases eller billeder | Før/efter-cases som vigtigste bevis |
| "Kontakt os" uden upload | Upload-først-formular på alle sider |
| Uklart hvad det koster | /priser/ med prismodeller og eksempler |
| Generiske stockfotos | Teknisk tegning som motiv, rigtige fotos af ejer og arbejde |

## De 10 mønstre – og hvor de bruges

| # | Mønster | Hvor på sitet |
|---|---|---|
| 1 | Værkstedstroværdighed som kernebudskab | Hero-lead, "Tegnet af en, der har stået ved maskinen", /om/ |
| 2 | Start med kundens problem | Sort problem-label over alle H1'er ("Venter produktionen på tegninger?") |
| 3 | Proces i 5 trin med konkrete løfter | Forside + /proces/ (Upload → 24 t → afklaring → fast pris → levering) |
| 4 | Upload-først-CTA på alle sider | CTA-sektion nederst på alle sider, header-knap, formular i ydelses-hero |
| 5 | Fleksible samarbejdsformer (A/B/C) | Forside, /proces/, /priser/ |
| 6 | Kundens egen tegningsramme | "Hvorfor ProCAD", FAQ, ydelser |
| 7 | Før/efter-cases | Forside, /cases/, ydelsessider |
| 8 | FAQ i kundens egne ord | /faq/ i 5 emner + uddrag på forsiden og ydelsessider |
| 9 | Dansk, DS/EN ISO, personlig kontakt – ikke pris | "Hvorfor ProCAD", /om/, footer |
| 10 | Gennemsigtig prissignalering | /priser/ (fast pris, timepris, timebank, eksempler) |

## Undgås bevidst

- Stockfotos af mennesker i hjelme og generiske industribilleder
- Store tal og statistikker, som en enkeltmandsvirksomhed ikke kan bakke op
- Lange tekstvægge uden visuel struktur
